# LDH Tools

Top-level landing page for The Lost Dogs' Home Cranbourne's internal tools. One access code, two destinations:

- **Shelter Stress Tool** — https://julianaxue-35.github.io/ldh-shelter-stress/ (dosing/recheck/wean calculators, animal attendant flag-check guide)
- **Shift Tools** — https://julianaxue-35.github.io/ldh-shift-tools/ (Surgery / Sick & Injured / Processing shift-recording tools)

This page is just a front door — it doesn't duplicate any of the other repos' content. Each destination keeps working at its own URL if bookmarked directly; this hub is an added convenience, not a replacement.

## Access

Gated client-side with an access code (`LDH2026`, shared with the other LDH tools) so the public URL isn't casually discoverable — this is not real security, only a casual deterrent, since the code is visible in the page source. Because all of Juliana's `julianaxue-35.github.io` sites share the same origin, unlocking the code once in a browser tab unlocks every other page under that domain too (`sessionStorage` is scoped per-origin, not per-path).
